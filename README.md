# FarmaStock

**FarmaStock** es un sistema local de gestión de inventario de medicamentos desarrollado como solución tecnológica para un pequeño negocio.

Su propósito es mejorar el control de productos, existencias, lotes, fechas de vencimiento y movimientos de inventario, facilitando además el registro de ventas y la generación de información útil para la gestión del negocio.

## Objetivo

Proporcionar una herramienta sencilla y funcional que permita mantener actualizado el inventario, reducir errores derivados del registro manual y apoyar el control de productos próximos a vencer o con existencias bajas.

## Contexto académico

Proyecto desarrollado para la asignatura **Asesoría Profesional** de la carrera de **Ingeniería en Desarrollo de Software** de la Universidad de El Salvador.

El proyecto parte del análisis de un negocio real y busca responder mediante una solución tecnológica a una oportunidad de mejora identificada durante el proceso de diagnóstico.
